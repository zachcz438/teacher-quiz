## 1. 背景与目标

### 1.1 v1 现状

- 30 题快测，5 类型（亲和力/逻辑专业/可爱活泼/故事表现/气场掌控）
- 每题 5 选 1，每选项映射到 1 个类型 → 简单计票决出主类型
- 单一报告，部署在 GitHub Pages，无后端

**局限**：类型粒度太粗、报告浅、单一视图、无数据沉淀、二元映射丢失大量信息。

### 1.2 v2 目标

升级为专业级教师风格测评，覆盖三个使用场景（按重要性排序）：

| 优先级 | 场景 | 设计承载 |
|--------|------|---------|
| **B（主）** | 教师培训机构用于教师发展 / 培养路径决策 | 机构版报告：能力诊断 + 培训处方 + 路径推荐 |
| **A（次）** | 在职/求职教师自我探索 | 老师版报告：共鸣感 + 类型角色 + 可分享 |
| **C（兜底）** | 招聘评估 | 反测谎机制 + 答题可信度评分 |

**核心约束**：测评本身必须"不严肃"，避免触发教师"被绩效评估"的应激反应。所有"判决性内容"（路径推荐、培训处方、风险预警）只在机构后台呈现，老师视角完全无感。

### 1.3 适用场景上下文

K-12 科学思维赛道（学而思培优类机构）。所有教师同科目（科学思维），主要差异点是年级段。

## 2. 测评框架

### 2.1 五维度连续画像

| 维度 | 高端 | 低端 | 含义 |
|------|------|------|------|
| **温度** | 温暖（W） | 冷静（C） | 情感投入 vs 专业距离 |
| **结构** | 严谨（R） | 灵活（L） | 计划性 vs 即兴 |
| **表达** | 外放（E） | 内敛（I） | 戏剧化 vs 沉静 |
| **控制** | 主导（D） | 赋能（G） | 我说了算 vs 学生主导 |
| **思维** | 感性（F） | 理性（T） | 共情驱动 vs 逻辑驱动 |

每维度 0-100 连续打分（不二分）。报告里**老师版用二元标签**（轻松感），**机构版用连续等级**（专业感）。

### 2.2 16 类型（Top-2 维度组合）

类型 = 最强 2 个维度的端向组合。从 C(5,2)×4=40 个原子组合中筛出 16 个有意义、互相区分的组合。

**命名遵循 MBTI 原则**：职能名词 / 2-3 字 / 完全性别中性 / 不依赖文化典故 / 每个名字暗示一种"超能力" / 正面调性。

| # | 类型 | 主调 | 辅调 | "超能力"暗示 | 现有 v1 映射 |
|---|------|------|------|-------------|-------------|
| 1 | **守望者** | 温暖 | 赋能 | 默默守护学生成长 | 亲和力型 ⬆ |
| 2 | **逻辑家** | 严谨 | 理性 | 严密构建知识体系 | 逻辑专业型 ⬆ |
| 3 | **演艺家** | 灵活 | 外放 | 把课堂玩成舞台 | 可爱活泼型 ⬆ |
| 4 | **吟游者** | 外放 | 感性 | 用故事点燃心灵 | 故事表现型 ⬆ |
| 5 | **统帅** | 严谨 | 主导 | 全局掌控、号令清晰 | 气场掌控型 ⬆ |
| 6 | **耕耘者** | 温暖 | 严谨 | 温暖中持续打磨 | — |
| 7 | **导师** | 温暖 | 理性 | 温润引领、循循善诱 | — |
| 8 | **使者** | 温暖 | 外放 | 传递温暖与知识 | — |
| 9 | **思辨家** | 冷静 | 理性 | 冷静批判思考 | — |
| 10 | **教练** | 严谨 | 赋能 | 严谨打磨 + 赋能成长 | — |
| 11 | **启发者** | 灵活 | 赋能 | 用提问引导自悟 | — |
| 12 | **策士** | 主导 | 理性 | 理性运筹、谋划全局 | — |
| 13 | **传播者** | 外放 | 理性 | 把复杂讲简单的话筒 | — |
| 14 | **观察者** | 内敛 | 感性 | 静默感知每个细节 | — |
| 15 | **演说家** | 严谨 | 外放 | 严谨内容 + 强场感染 | — |
| 16 | **倾听者** | 温暖 | 内敛 | 给学生稀缺的"被看见" | — |

v1 的 5 类型作为 #1-5 升级保留，文案/题目可平滑迁移。

### 2.3 五大家族分组（参考 Keirsey 16 型分组法）

把 16 型按主导维度归属到 5 个家族，给老师"我和守望者是同族"的归属感：

| 家族 | 共性 | 包含类型 |
|------|------|---------|
| 🌱 **守护族**（5） | 温度为底色 | 守望者、耕耘者、导师、使者、倾听者 |
| 🧠 **思辨族**（4） | 理性为底色 | 逻辑家、思辨家、策士、传播者 |
| 🎭 **舞台族**（3） | 表达为底色 | 演艺家、吟游者、演说家 |
| ⚔️ **掌控族**（2） | 主导/规则为底色 | 统帅、教练 |
| 💡 **引路族**（2） | 赋能/启发为底色 | 启发者、观察者 |

家族不强求等分（MBTI 4×4 是巧合，自然分布更重要）。家族在老师版报告里作为"你属于 🌱 守护族"展示，可分享性强。

### 2.4 二元画像标签（替代雷达图）

每个老师拿到 5 个标签（每维度按主导端给一个），类似 MBTI 的 e/i：

| 维度 | 高端标签 | 低端标签 |
|------|---------|---------|
| 温度 | #暖系 | #冷系 |
| 结构 | #严谨派 | #即兴派 |
| 表达 | #外放派 | #沉静派 |
| 控制 | #指挥型 | #引路型 |
| 思维 | #感性派 | #理性派 |

**作用**：老师视角的"主可视化"，替代雷达图。便于记忆、便于聚类、便于在小红书等平台传播（"我是 #暖系 #即兴派 老师"）。

### 2.5 5 字母代码（MBTI 极客感）

每个老师的画像由 5 个字母代码标记（W/C, R/L, E/I, D/G, F/T 各取一个），如 **WLEGF** = 温暖+灵活+外放+赋能+感性。

**注意**：5 字母代码 ≠ 16 类型。代码记录每个老师的"维度全画像"，类型由代码中最强 2 个端向决定。同一类型（如守望者 W+G）下的不同老师代码不同（如 WLEGF / WSEDF 都属守望者，只是其他 3 维度有差异）。

老师可在报告里看到自己的 5 字母代码，用于身份感、搜索匹配和小红书晒号。

## 3. 三类潜力评估

| 潜力类型 | 含义 | 测量方式 | 报告呈现 |
|---------|------|---------|---------|
| **成长潜力（A）** | 还能进化多远（学习意愿、反思力、对反馈的开放度） | 5 道额外的"成长心态"题 → 0-100 分 → A/B/C/D 评级 | 仅机构版。老师版不显示。 |
| **风格上限（B）** | 在主类型里能多顶尖 | 主维度的极致度 + 一致性推算 → A/B/C/D 评级 | 仅机构版（老师版的"风格亮点"段落用软性叙事承载） |
| **路径潜力（D）** | 与 7 个职业岗位的匹配度 | 余弦相似度 + 短板惩罚 → 排序 | 仅机构版（老师版完全不显示） |

## 4. 七个职业岗位（机构版"路径匹配度"）

| # | 岗位 | 一句话职责 | 理想画像 |
|---|------|---------|---------|
| 1 | 主讲老师 | 大班讲课、控场、续保服务 | 表达↑↑ + 控制主导↑↑ + 思维理性↑ + 温度↑ |
| 2 | 刷题班老师 | 题目讲解、错题复盘、训练带练 | 思维理性↑↑ + 结构严谨↑↑ + 控制主导↑ |
| 3 | 教研老师 | 教案设计、课件开发、教学研究 | 思维理性↑↑ + 结构严谨↑↑ + 内敛↑ |
| 4 | 培训师 / 师训 | 培训新老师、师资输出 | 表达↑ + 控制主导↑ + 结构严谨↑ + 思维理性↑（最综合）|
| 5 | 教学主管 | 团队管理、排课、跨部门协同 | 控制主导↑↑ + 结构严谨↑↑ + 温度中 |
| 6 | 学科老师 | 讲讲座、招生、起声量、学科带头 | 表达↑↑ + 感性↑↑ + 温度↑ + 控制主导↑ |
| 7 | 拔尖班 / 集训队老师 | 教尖子生、竞赛培训 | 思维理性↑↑↑ + 结构严谨↑↑ + 控制主导↑ + 表达中 |

**已剔除**：顾问老师（销售岗，不参与教学测评）、教务老师（不做测评）。

## 5. 五个年级段（机构版"年级匹配度"）

| 年级段 | 学生特点 | 老师理想画像 |
|-------|---------|-------------|
| 学前（K1-K3） | 注意力短、情感驱动、游戏化、思维启蒙包装在游戏里 | 表达↑↑↑ + 温度↑↑↑ + 灵活↑↑ + 控制赋能↑ + 思维理性↑ |
| 小学低段（1-2） | 喜欢老师=喜欢学科、规则建立期、需要趣味+情感 | 温度↑↑ + 表达↑↑ + 结构↑ + 控制赋能↑ + 思维理性↑ |
| 小学中段（3-4） | 抽象思维起步、趣味+逻辑都要 | 温度↑ + 表达↑ + 结构↑ + 思维理性↑↑ + 控制过渡 |
| 小学高段（5-6） | 准青春期、要被尊重、喜欢挑战、学业压力开始 | 思维理性↑↑ + 结构严谨↑ + 控制主导↑ + 表达中 + 温度中 |
| 小学以上（初中+高中） | 自驱强、高知识深度、专业感重于情感 | 思维理性↑↑↑ + 结构严谨↑↑ + 控制主导↑↑ + 内敛↑ + 温度中 |

**算法**：余弦相似度 + 致命短板硬扣分（如教学前老师温度<30 直接扣 30%）。

## 6. 题目体系

### 6.1 题量分级

| 版本 | 题量 | 时长 | 信度 | 用途 |
|------|------|------|------|------|
| 基础版 | 30 题（5 维 × 5 + 5 题潜力）| 3 分钟 | ~0.75（实用级下限）| A 场景流量入口 |
| 专业版 | 60 题（5 维 × 10 + 5 题潜力扩展 + 5 题反测谎）| 8 分钟 | ~0.85（专业级）| B/C 场景主力 |

**关键设计原则**：基础版 30 题 = 专业版 60 题的子集。两版本分数可比、类型一致。

### 6.2 题型范式（混合）

| 占比 | 题型 | 作用 |
|------|------|------|
| 70% | 情境多维打分题 | 主力。每选项对多维度有不同权重（-10 到 +10） |
| 25% | 强迫二选一 | 关键维度纯化，避免社会期望度污染 |
| 5% | 反测谎陷阱题 | 反向重复 + 社会期望度题，输出"答题可信度" |

### 6.3 题目示例

**情境多维打分题（主力）**

> 一个孩子在课堂上突然哭了，你的第一反应——
> ① 蹲下抱抱他，先安抚情绪再问原因 → 温度+8 / 控制主导−3 / 表达+2
> ② 让其他孩子继续做题，把他带出去单独聊 → 控制主导+5 / 结构+3 / 温度+4
> ③ 假装没看见继续讲课，给他时间自己平复 → 控制主导+5 / 温度−5 / 结构+2
> ④ 当场讲一个"小时候我也这样"的故事让他破涕为笑 → 表达+9 / 温度+6
> ⑤ 严肃问"现在是上课时间，能告诉我怎么了吗" → 控制主导+8 / 温度−3 / 结构+5

**强迫二选一**

> 一节课如果只能保证一件事——
> ① 每个孩子都被关注到 [温度极端]
> ② 知识点没有任何遗漏 [理性极端]

**反测谎**

- **反向重复**：第 8 题问"我喜欢按计划上课"，第 35 题问"我享受即兴发挥的课堂"——前后矛盾打"作答不一致"标签
- **社会期望度**：纯白莲花选项（如"我从来不对学生发脾气"）→ 选了加"美化倾向"权重

### 6.4 现有题处理

- v1 的 30 题改造保留（重新标定多维权重）
- 补 30 题达到 60 题
- 重写题目时确保**基础版 30 题是专业版 60 题的子集**

## 7. 双视图报告设计

### 7.1 老师视角报告（轻松调性，6 sections）

**设计原则**：去掉所有"判决感"内容，强化"画像感"和"共鸣感"。整体调性 = 16personalities × 网易云人格测试。

| # | Section | 内容 |
|---|---------|------|
| ① | 类型卡 Hero | 角色名 + emoji + 5 字母代码 + 一句话定位 |
| ② | 画像标签 | 5 个二元标签（#暖系 #即兴派 等），替代雷达图 |
| ③ | 你这个人 | 个人剖析段落（先共鸣"在朋友眼里你..."，再桥接"正因为你是这样的人，在讲台上..."）|
| ④ | 教学画像 | 你的超能力（3 个，叙事化）+ 你的小弱点（2 个，温和指出）|
| ⑤ | 风格亮点 | 深度文字段落（"在所有暖系老师里，你的特别之处..."），承载"风格上限 B"的软性表达 |
| ⑥ | 行动区 | [重新测试] [生成分享卡（PNG）] |

**老师视角"无内容"清单**（明确不放）：
- ❌ 雷达图（用二元标签替代）
- ❌ 路径推荐 / 岗位匹配度
- ❌ 年级匹配度
- ❌ 成长潜力指数
- ❌ 任何具体分数
- ❌ "深度解读"按钮（不暴露专业版存在）
- ❌ 任何"机构在看你"的暗示（如"分享给主管""导出报告"按钮）

### 7.2 机构视角报告（专业调性，6 sections）

**设计原则**：保留专业深度但去掉"考试分数感"，用等级 + 百分位 + 形容词替代纯数字打分。

| # | Section | 内容 |
|---|---------|------|
| ① | 老师档案 | 姓名 / 工号 / 测评时间 / 答题可信度 / 美化倾向 / 测评版本 |
| ② | 风格画像 | 主类型 + 5 维分布（雷达图 + 等级文字）+ 关键词标签 |
| ③ | 三类潜力评估 | 成长潜力（A 级 · 高可塑）、风格上限（A 级 · 头部 13%）、路径潜力 Top3 |
| ④ | 岗位匹配度 | 7 岗位匹配排序，每个用 ★★★★★ + 百分位 |
| ⑤ | 年级匹配度 | 5 段年级匹配排序 + 致命短板预警（如"教小学以上需补强结构维度"）|
| ⑥ | 培训处方 + 风险预警 | 短期/中期/长期建议；不适合岗位预警；优势场景与警惕场景 |

**机构版分数体系**：

| 原打分 | 改为 |
|-------|------|
| "成长潜力 87 分" | "成长潜力 A 级 · 高可塑" |
| "班主任匹配 92%" | "班主任匹配 ★★★★★ · 头部 8%" |
| "温度维度 81 分" | "温度维度 强 · 在亲和系老师中典型" |

### 7.3 报告深度分层（基础版 vs 专业版）

| | 基础版（30 题） | 专业版（60 题） |
|---|---------------|---------------|
| 老师版 | 类型卡 + 标签 + 短剖析 + 简短亮点（约 800 字） | 完整 6 sections（约 2500 字）|
| 机构版 | 类型 + 三大潜力等级 + 岗位 Top3 + 年级 Top2 + 轻处方 | 完整 6 sections + 详细处方 + 风险预警 |

## 8. 视觉设计

### 8.1 风格定位：温暖手账风

**目标**：彻底去掉"AI 启动页"的工业感（渐变光晕、blob 背景、glow 按钮、千篇一律的 emoji）。

**视觉语言**：
- **底层**：纸质纹理（米色、牛皮纸色）
- **装饰元素**：手绘插画、胶带、便利贴、印章、手写体点缀
- **色彩**：当前的 coral/mint/lavender 收敛为 1-2 个主色 + 黑白灰 + 暖米色
- **去除**：所有 blob 动画背景、glow 阴影、纯渐变按钮
- **字体**：
  - 标题：衬线体（Source Han Serif 思源宋体）
  - 正文：Noto Sans SC
  - 点缀：手写体（汉仪手书 / 方正手迹）

### 8.2 机构版的风格适配

机构版用同套手账风视觉系统，但做"专业化适配"：
- 报告卡片底仍有手账纹理，但**数据展示部分（表格、进度条、等级 badge）保持清爽**
- 减少装饰元素（少胶带、少手写字体）
- 内容部分保持干净排版

→ 老师版 = 全套手账风 / 机构版 = 手账风的克制专业子集

### 8.3 关键 UI 组件清单

- 入口版本选择卡（基础版 30 题 / 专业版 60 题）
- 16 类型展示墙（开始页可滑动浏览所有类型，提升入口好奇感）
- 二元标签胶囊（5 个 emoji + 词）
- 进度条（60 题需要更稳的进度提示）
- 等级 badge（A/B/C/D 评级展示）
- 报告卡片堆叠布局（6 sections 可滚动）
- **分享卡生成（导出 PNG）**：老师测完最重要的传播触点
- 5 字母代码胶囊（如 WLEGF）

## 9. 技术架构

### 9.1 前端

- **框架**：Astro（静态生成）
- **语言**：TypeScript
- **样式**：Tailwind CSS（按需引入）
- **部署**：构建出纯静态文件，托管在阿里云 OSS + CDN 或 ECS nginx

### 9.2 后端

- **运行时**：Node.js + Express
- **数据库**：SQLite（单文件，万级老师够用）
- **进程守护**：pm2
- **反向代理**：nginx
- **部署**：阿里云 ECS（Linux）

### 9.3 路由设计

**前端路由**

| 路径 | 内容 | 访问 |
|------|------|------|
| `/` | 入口（选基础/专业版 + 浏览 16 类型） | 公开 |
| `/quiz/basic` | 基础版测评（30 题） | 公开 |
| `/quiz/pro` | 专业版测评（60 题） | 公开 |
| `/report/:token` | 老师版报告（凭 token 重看） | 公开（凭 token） |
| `/admin` | 机构后台（密码保护登录页） | 公开访问，需登录 |
| `/admin/list` | 老师列表 | 登录后 |
| `/admin/teacher/:id` | 单老师机构版报告 | 登录后 |

**老师"无感"机制的关键点**：
- 老师页面**不存在**任何指向 `/admin` 的链接
- 老师 token 仅用于"重看自己的老师版报告"
- 机构后台 URL 单独发给机构方，不在老师页面任何地方暴露

**后端 API**

| 方法 | 路径 | 作用 |
|------|------|------|
| POST | `/api/submit` | 提交答题，返回老师 token + 老师版报告数据 |
| POST | `/api/admin/login` | 后台登录，返回 admin session |
| GET | `/api/admin/list` | 老师列表（分页、筛选） |
| GET | `/api/admin/detail/:id` | 单老师完整数据（机构版报告所需） |
| GET | `/api/admin/export/:id` | 导出 PDF（v1.5 加） |

### 9.4 数据库 Schema

```sql
CREATE TABLE submissions (
  id TEXT PRIMARY KEY,           -- UUID
  token TEXT UNIQUE NOT NULL,    -- 老师重看报告的 token（短码 8 位）
  org_id TEXT,                   -- 机构 ID（v1 默认值，v2 多机构时启用）
  teacher_name TEXT,             -- 老师姓名（必填）
  teacher_code TEXT,             -- 工号（可选）
  version TEXT NOT NULL,         -- 'basic' | 'pro'
  answers JSON NOT NULL,         -- 完整作答 [{q:1, a:'A'}, ...]
  scores JSON NOT NULL,          -- 五维度连续分数 + 三潜力分数
  type_id INTEGER NOT NULL,      -- 1-16 类型
  type_name TEXT NOT NULL,       -- 暖心园丁
  type_code TEXT NOT NULL,       -- WLEGF
  tags JSON NOT NULL,            -- 5 个二元标签
  job_match JSON,                -- 7 岗位匹配度（仅 pro 版生成）
  grade_match JSON,              -- 5 年级匹配度（仅 pro 版生成）
  growth_potential JSON,         -- 成长潜力（仅 pro 版生成）
  credibility JSON,              -- 答题可信度 + 美化倾向（仅 pro 版生成）
  created_at INTEGER NOT NULL,   -- 时间戳
  user_agent TEXT,               -- 设备/UA
  ip_hash TEXT                   -- IP 哈希（防刷）
);

CREATE INDEX idx_submissions_org ON submissions(org_id, created_at);
CREATE INDEX idx_submissions_teacher ON submissions(org_id, teacher_name);
CREATE INDEX idx_submissions_token ON submissions(token);

CREATE TABLE admin_users (
  id TEXT PRIMARY KEY,
  username TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  org_id TEXT NOT NULL,
  created_at INTEGER NOT NULL
);

CREATE TABLE admin_sessions (
  token TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  expires_at INTEGER NOT NULL,
  created_at INTEGER NOT NULL,
  FOREIGN KEY (user_id) REFERENCES admin_users(id)
);
```

**v2 拓展所需字段**（v1 schema 已预留）：
- `org_id` → 多机构隔离
- `created_at` 索引 → 成长轨迹查询
- `(org_id, teacher_name)` 索引 → 同一老师多次测评聚合
- `scores` 完整保留 → 批量画像分析

### 9.5 阿里云 ECS 部署注意

| 项目 | 说明 |
|------|------|
| **OS** | Linux（Ubuntu 22.04 / Alibaba Cloud Linux 推荐） |
| **域名** | 如使用国内域名（.cn 或 国内访问要求），**必须做 ICP 备案**，周期 7-20 天 |
| **HTTPS** | 阿里云免费 SSL 证书（DV 单域名免费 1 年），nginx 配置反向代理到 Node |
| **安全组** | 仅开放 80 / 443 端口，Node 服务（如 3000）不对外暴露 |
| **数据备份** | SQLite 文件每日定时备份到阿里云 OSS（cron + ossutil） |
| **进程管理** | pm2 守护，开机自启 |
| **监控** | 阿里云云监控（免费基础版即可） |

## 11. 风险与限制

| 风险 | 缓解 |
|------|------|
| 信度依赖样本量，初期结果可能不稳 | v1 不强行做对标功能；机构版报告标注"基于个人作答" |
| 老师"应试"答题（猜测想要的答案） | 反测谎机制 + 题目尽量避免明显的"对错"暗示 |
| 16 类型边界处理（接近 50/50 时类型抖动） | 取 Top-2 强维度而非二元划分；连续分数为底，类型为表 |
| ICP 备案时间窗口 | 提前启动；过渡期可用海外域名做内测 |
| 阿里云成本 | 入门 ECS 100 元/月可承载 v1；SQLite 无单独 DB 成本 |
| 视觉风险：手账风 vs 机构专业感 | 同套色彩+字体系统，机构版减装饰、保数据清爽 |
